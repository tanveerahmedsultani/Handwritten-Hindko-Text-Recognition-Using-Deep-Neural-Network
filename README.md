# Handwritten Hindko Text Recognition Using Deep Neural Network

This repository contains the **thesis, source code, and data-processing code** for the research project **"Handwritten Hindko Text Recognition Using Deep Neural Network."**

The project focuses on developing a deep learning-based system for recognizing handwritten text in the **Hindko language**, contributing to research in low-resource language processing and handwritten text recognition.

## 📌 Project Overview

Hindko is a low-resource language for which relatively limited computational resources and publicly available datasets exist. This research investigates the use of **Deep Neural Networks (DNNs)** for recognizing handwritten Hindko text.

The project includes:

* Handwritten Hindko text dataset preparation
* Image preprocessing
* Conversion of handwritten image data into a structured format
* Deep learning-based handwritten text recognition
* Model training and evaluation
* Performance analysis
